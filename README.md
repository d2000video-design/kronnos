# KRONNOS — Construcción y Rehabilitación

Sitio estático en español: HTML, CSS y JavaScript, compatible con GitHub y Vercel.

## Publicación

Contenido de esta carpeta en la raíz del repositorio. Vercel: preset Other, comando `npm run build`, salida `dist`.

## Contenido y contacto

Seis proyectos, doce imágenes en formato 4:3 y galería ampliada con navegación por botones y teclado. Las etapas recreadas mediante IA se identifican debajo de las imágenes. La portada muestra montaje de tabiques, sin vivienda de catálogo.

Responsable técnico: Roberto Rueda. Teléfono y WhatsApp: +34 695 04 11 47. Contacto directo y botón flotante. Sin formularios ni almacenamiento de datos.

Configuración: `site-config.js`. Diseño: `styles.css`. Interacciones: `script.js`.

## Desarrollo

Node.js 20+. `npm start` abre servidor en puerto 4173. `npm run build` genera `dist`.
